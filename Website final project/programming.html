Python: Is it as scary as the snake?

Python is the second programming laungague I have learned. It is one I both love and hate. There are so many cool things you can do with python, but you've got to be good at creating the logic. I took the beginner class summer of 2025, and took the advanced course in fall of 2025. I am grateful to learn this wonderful programming langauge, but I would be lying if I said I wanted to work with it on a daily basis. As time progresses, maybe I will learn to like it more.


HTML and CSS: The markup languages

If you google, "are html and css programming languages?" The answer you will get is no, they are markup langauges. You will also find that whether or not web developers are "real" programmers appears to be a heated debate. While I can see both sides, I don't think a web developer is any less important that say a python programmer. Learning about HTML and CSS fall semester of 2025 has been so fun. And look, I have this fun website to show off the skills I gained. I thought web design would be something I never touched again after the course I took, but now, I hope to independently expand my skills and turn it into a larger hobby in the future. I have a full list of websites I would love to create and design some day.
